# mini-e-commerce

A backend e-commerce platform built with **C#**, **ASP.NET Core**.

## Project Overview

This project aims to build a scalable e-commerce system using independent microservices that communicate through REST APIs and Apache Kafka.

## Tech Stack

- **Backend:** C#, ASP.NET Core Web API
- **Architecture:** Microservices, Event-Driven Architecture
- **Message Broker:** Apache Kafka
- **Database:** PostgreSQL
- **Cache:** Redis
- **API Gateway:** YARP
- **ORM:** Entity Framework Core
- **Containerization:** Docker

## Core Services

- **Auth Service:** User authentication and authorization.
- **Product Service:** Product and category management.
- **Order Service:** Order processing and management.
- **Inventory Service:** Stock management.
- **Payment Service:** Payment processing.
- **Notification Service:** Email notifications.

## Goals

Explore and implement microservices architecture, asynchronous communication with Kafka, distributed data management, and scalable backend system design.
